# 银龄智城 V3：给已经公网部署的团队的逐步升级清单

## 目标

从只有“问题录入—风险评分—预算优化”的3页演示版升级到5页：增加出行链空间联动、分组通行能力档案、可上传的社区路网、预算公平性对比与项目边际解释。

本版不含自动视觉识别，不声称符合工程安全认证要求。演示地图和实验均用合成数据启动。



10. 到 `outputs/results` 查看 `demo_network_experiment.csv`，`outputs/charts` 查看 `demo_network_experiment.png`。

## C. 实地数据：三张CSV怎么准备

建议2—3名队员选**一个安全、可公开调查的步行小片区**，最好有3栋建筑、1—3个生活服务点、10—20段实测道路。不要进入机动车道或私有区域，不拍摄可识别个人。

### ① nodes.csv（节点表）

在 Excel 中新建工作簿，第一行填写：

`node_id,name,lat,lon,kind`

例子：`h1,某栋楼入口,真实纬度,真实经度,住宅`。纬度经度可用六位小数。`kind`只允许住宅/路口/卫生站/公交站/菜市场/公共服务等；至少有1个住宅、1个目的地。坐标系应统一，尤其不能直接混用高德GCJ-02与OSM的WGS84。

### ② edges.csv（道路段表）

在另一个 Excel 表第一行填写：

`start,end,length_m,blocked_for,repair_project_id,verified`

- `start`和`end`是nodes表中的节点ID，例如h1和a。
- `length_m`是实地核实或明确估算的长度（米）。
- `blocked_for`是人工判定的限制档案，如`轮椅;助行器`；没有确定障碍可留空。但**未知不等于确认安全**。
- `repair_project_id`是解决该阻断问题的项目编号，例如P013，必须与项目表一一对应。
- `verified`用TRUE/FALSE。对正式评估建议先专业复核，不可简单因为照片看着平整就标TRUE。

### ③ problems.csv（改造项目表）

点击网页“问题采集”录入真实问题，选择「实地调查」并填写成本、严重度、受影响人数代理值、频率、改造改善程度；现场复核后才选「已核验」。再点击导出CSV。注意导出的新编号需要同步更新edges.csv的repair_project_id。初始演示P001等不等于真实位置。

### 文件保存

Excel → 文件 → 另存为 → `CSV UTF-8（逗号分隔）`，分别保存 `nodes.csv` / `edges.csv` / `problems.csv`。先核查列名、经纬度、空值、项目ID。

### 在网页中上传与运行

1. 打开“⑤片区路网与人群差异”；同时上传nodes.csv和edges.csv；确认已显示「用户上传数据」。
2. 上传problems.csv；真实模式只筛选 `source_type=实地调查` 且已核验的改造候选项。
3. 选择「轮椅」和“仅把人工核验的道路当作已知可通行路段”。
4. 预算分别取3、5、10万元；记录传统方法/空间方法的完整可达链、最低楼栋可达率、预算支出。
5. 在下方「为什么推荐」查看哪些完整路线需要某个项目；截图并导出CSV。结果属于建模与仿真，不是工程改造真实效果。
6. 上传文件只保存在浏览器这次会话中；退出可能丢失。请在自己电脑保存CSV备份，勿把隐私数据写入公开GitHub。

## D. 可复现实验与简明创新描述

1. 实验I：A只按严重度，B按收益/成本，C传统0-1背包，D含出行链+弱覆盖楼栋的组合优化。使用相同样本、相同预算。
2. 实验II：在3万元/5万元/10万元三个预算下比较「模型可达OD链比例」和「最低楼栋可达率」；结果非实地改造绩效。
3. 实验III：依次改变 `出行链改善权重`与`弱覆盖楼栋优先权重`，观察方案是否稳定，并说明换取空间覆盖时牺牲了多少传统收益分。
4. 实验IV：同一改造组合在「一般步行、助行器、轮椅」三种预设通行能力档案下分别计算。档案不是老年群体实际能力标签。
5. 若需要在本机保存实际调查实验结果，将三张已脱敏数据放在电脑的私有目录，执行：

```bat
python scripts/run_network_experiment.py --nodes "C:\survey\nodes.csv" --edges "C:\survey\edges.csv" --projects "C:\survey\problems.csv"
```

运行结果在 `outputs/results/field_network_experiment.csv` 和 `outputs/charts/field_network_experiment.png`。**不要上传真实敏感原始数据到GitHub公开仓库**。
